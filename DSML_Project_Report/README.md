## For Project Reviewers

### Quick Navigation

- **Full Report:** Start with [`report/DSML_Project_Report.md`](report/DSML_Project_Report.md) - this is the main 100-page deliverable containing all 5 case studies with detailed analysis, visualizations, and recommendations.

- **Individual Case Studies:** Each folder in `case_studies/` contains a README with a summary of that specific case study.

- **Code Reference:** The `appendix/code_snippets.md` file contains reusable Python code from all case studies.

- **Statistical Reference:** The `appendix/statistical_tables.md` file contains all statistical formulas and reference tables used.
