# Case Study 1: Netflix - Data Exploration and Visualisation

**Score:** 95.0/100 | **Status:** Completed | **Due Date:** 26 Aug 2025

## Overview
Comprehensive analysis of the Netflix dataset to provide data-driven recommendations
for content production and global growth strategy.

## Business Problem
1. Determine what types of content (movies/TV shows) Netflix should focus on producing.
2. Identify key markets and strategies for business growth in different countries.

## Dataset
- Source: Netflix content catalog (mid-2021)
- Attributes: show_id, type, title, director, cast, country, date_added, release_year, rating, duration, listed_in, description

## Techniques Used
- Exploratory Data Analysis (EDA)
- Data Visualization (countplots, bar charts, histograms, heatmaps)
- Missing value analysis
- Trend analysis across time and geography

## Tools
- Python, Pandas, NumPy, Matplotlib, Seaborn, Google Colab

## Key Findings
- Movies dominate the platform, but TV shows are on the rise
- US and India are top content hubs
- Content skews towards recent releases (post-2010)
- Primary audience is adults and teens (TV-MA, TV-14)
- Gap in kids and family content
