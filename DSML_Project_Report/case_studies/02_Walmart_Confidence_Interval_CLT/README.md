# Case Study 2: Walmart - Confidence Interval and Central Limit Theorem

**Score:** 94.0/100 | **Status:** Completed | **Due Date:** 21 Oct 2025

## Overview
Analysis of Walmart Black Friday transaction data to understand customer spending
patterns by gender, age group, marital status, and city category using statistical
inference techniques.

## Business Problem
Walmart wants to analyze customer purchase behavior during Black Friday to determine
if spending habits differ by gender, marital status, and age group.

## Dataset
- Shape: 550,068 rows x 10 columns
- Key columns: User_ID, Product_ID, Gender, Age, Occupation, City_Category,
  Stay_In_Current_City_Years, Marital_Status, Product_Category, Purchase

## Techniques Used
- Confidence Interval estimation (Analytic and Bootstrap)
- Central Limit Theorem demonstration
- Exploratory Data Analysis
- Group comparison (gender, age, marital status)

## Tools
- Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy

## Key Findings
- Males spend ~700 more per transaction than females (statistically significant)
- Marital status has no significant effect on spending
- Age 26-50 is the highest spending segment
- CLT validated: larger samples yield narrower confidence intervals
