# Case Study 4: Aerofit - Descriptive Statistics and Probability

**Score:** 86.0/100 | **Status:** Completed | **Due Date:** 28 Sep 2025

## Overview
Customer profiling analysis for AeroFit treadmill products using descriptive statistics,
probability distributions, and customer segmentation techniques.

## Business Problem
AeroFit needs to understand customer profiles for each treadmill model to improve
marketing strategy and product recommendations.

## Products
- KP281: Entry-level ($1,500)
- KP481: Mid-level ($1,750)
- KP781: Advanced ($2,500)

## Dataset
- Shape: 180 rows x 9 columns
- Key columns: Product, Age, Gender, Education, MaritalStatus, Usage, Income,
  Fitness, Miles

## Techniques Used
- Descriptive Statistics
- Marginal and Conditional Probability
- Univariate and Bivariate Analysis
- Outlier Detection (Box plots, IQR)
- Correlation Analysis

## Tools
- Python, Pandas, NumPy, Matplotlib, Seaborn

## Key Findings
- 44% buy KP281, 33% KP481, 22% KP781
- Males are 3x more likely to buy KP781 than females
- Younger customers (18-28) prefer KP281; older/high-income (30-40) prefer KP781
- Fitness, Usage, and Miles are strongly correlated
