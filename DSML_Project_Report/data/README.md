# Data Directory

This directory is a placeholder for dataset files used across the 5 case studies.

## Dataset Sources

| Case Study | Dataset | Size | Source |
|-----------|---------|------|--------|
| Netflix | netflix_titles.csv | ~8,800 rows x 12 cols | Kaggle / Scaler |
| Walmart | walmart_data.csv | 550,068 rows x 10 cols | Scaler |
| Yulu | bike_sharing.csv | 10,886 rows x 12 cols | Scaler |
| Aerofit | aerofit_treadmill.csv | 180 rows x 9 cols | Scaler |
| LoanTap | LoanTapData.csv | 3,000 rows x 27 cols | Scaler |

## How to Access

The datasets are available in the individual GitHub repositories:

- Netflix: [Netflix-Content-Strategy-Analysis](https://github.com/MateenahJAHAN/Netflix-Content-Strategy-Analysis)
- Walmart: [Walmart-Black-Friday-Sales-Analysis](https://github.com/MateenahJAHAN/Walmart-Black-Friday-Sales-Analysis)
- Yulu: [Yulu-Electric-Cycle-Demand-Analysis-](https://github.com/MateenahJAHAN/Yulu-Electric-Cycle-Demand-Analysis-)
- Aerofit: [AeroFit-Treadmill-Customer-Profiling](https://github.com/MateenahJAHAN/AeroFit-Treadmill-Customer-Profiling)
- LoanTap: [Predictive-Analytics-in-Asymmetric-Data](https://github.com/MateenahJAHAN/Predictive-Analytics-in-Asymmetric-Data-A-Robust-Classification-Framework)

**Note:** Large data files are not included directly in this report repository to keep it lightweight.
