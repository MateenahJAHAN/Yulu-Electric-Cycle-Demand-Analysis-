## Business Problem Captured

- AeroFit offers three treadmill models:
  - KP281 (entry-level)
  - KP481 (mid-level)
  - KP781 (advanced)
- Need to profile customers by product preference and support product-positioning decisions.

## Analytical Flow Observed

1. Data import and structure check
2. Outlier evaluation
3. Univariate and bivariate analysis
4. Marginal and conditional probability analysis
5. Correlation review
6. Customer-profile construction and recommendations

## Key Signals Captured for Template

- Dataset size reported: 180 rows, 9 columns
- Typical features: age, gender, marital status, usage, fitness, income, miles
- Premium model preference linked with higher-income/higher-fitness segments
- Clear business recommendation pattern by model tier
